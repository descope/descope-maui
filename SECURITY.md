# Security policy

## Reporting a vulnerability

Do not open a public issue. Report it privately through GitHub: on this repository's **Security** tab, choose **Report a vulnerability**.

Include the affected version, what an attacker can do, and the steps to reproduce. We will keep you updated until a fix is released.

## Supported versions

Only the latest release receives security fixes.

## Scope

In scope: this SDK's handling of tokens, session storage, the OIDC flow (PKCE, state, redirects) and the hosts it sends credentials to.

Out of scope: vulnerabilities in the Descope service itself, which should be reported through Descope's own security channels, and issues in your app or backend.
